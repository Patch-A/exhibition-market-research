# 米奥兰特项目与市场选择

## 适用范围

本规则约束报告中的展会推荐和“指定市场之外”的市场推荐。米奥兰特项目是唯一的推荐候选池；联网搜索只能核验项目当前状态、时间、地点、展品范围和当地市场条件，不能自行补充其他主办方展会作为替代推荐。

## 唯一项目候选池

首次适配时，将“米奥兰特项目/展会”映射到当前智能体已经接入的项目入口、飞书 Base 或可访问的项目记录，不新建表。至少确认以下字段：

| 字段 | 用途 |
| --- | --- |
| 项目 ID、项目名称 | 让摘要、展会章节和行动计划引用同一个项目 |
| 米奥兰特归属或项目标签 | 证明项目属于米奥兰特推荐范围 |
| 国家/地区、城市、场馆 | 判断市场和执行地点 |
| 展会日期、报名/举办状态 | 按当前日期判断是否仍可推荐 |
| 产品/行业范围 | 判断与输入产品的匹配度 |
| 历史参展、展商、买家或现场记录 | 判断获客对象和项目经验 |
| 内部记录链接或来源编号 | 回链内部证据并区分权限范围 |

如果无法确认某项目属于米奥兰特，不能把它放入推荐项目池。只能标记为外部观察或待核验，不得出现在“推荐展会”表中。

## 当前项目筛选

以系统当前日期为基准，按以下顺序筛选：

1. 过滤掉已结束、取消、延期且新日期未确认的项目；历史项目只能用于历届参展和同行案例。
2. 保留国家/地区与目标市场相同，或明确服务该市场的项目。
3. 保留产品、行业或买家角色与输入产品匹配的项目；只有地域相同不能算产品匹配。
4. 打开外部项目页面核验当前日期、地点、状态和展品范围；内部记录与外部页面冲突时保留差异并降级。
5. 按产品匹配、国家匹配、当前有效性、目标买家可触达性和证据完整度排序，最多推荐有证据的项目。

每一个推荐项目必须拥有唯一项目 ID，并在执行摘要、市场推荐、展会章节和行动计划中使用相同的项目名称和 ID。执行摘要出现的推荐项目必须在第 9 节出现，第 9 节不能新增摘要未解释的项目。

## 指定市场之外的市场推荐

用户指定目标市场时，先研究该市场；另外的市场只能从当前有效、属于米奥兰特且与产品匹配的项目国家/地区中选 1-2 个。每个额外市场必须同时具备：

- 米奥兰特项目 ID、项目日期、国家/地区和产品匹配证据；
- 按当前日期核验的当地市场需求、渠道或项目机会；
- 关税、准入、政策利好或其他进入条件的当前证据；
- 明确的推荐原因、主要风险和 30 天验证动作。

没有符合条件的米奥兰特项目时，不得用模型常识或公开展会名单补出替代市场。应写明“当前项目库没有足够匹配的额外推荐市场”，并列出待补充的项目字段或市场证据。

## 展会与替代获客渠道的关联

替代获客渠道必须服务于已选米奥兰特项目，例如展前预约、项目展商目录、观众/买家邀约、现场样品验证和展后跟进。可以提出 LinkedIn、渠道拜访或本地目录等动作，但必须说明它们服务哪个项目、对应哪个目标买家和哪个验证指标。

不得把与米奥兰特项目无关的公开展会写成替代展会或主推荐。若没有合格项目，输出项目缺口和市场验证动作，不输出泛化展会清单。
