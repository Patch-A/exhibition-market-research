# 研究证据与引用

## 联网搜索核验流程

联网搜索结果只负责发现候选来源，不等于已经核验。对每个准备写入报告的外部事实，按 [research-routing.md](research-routing.md) 选择对象对应的首选来源顺序；对公网优先对象不得先用内部库结果替代公网证据。按以下顺序执行：

1. 用企业、产品、国家、展会或政策关键词搜索候选来源，并保留候选 URL。
2. 打开候选网页正文，确认页面标题、发布方、发布日期/更新时间或生效日期。
3. 定位能直接支持命题的正文、表格、数据库字段或官方公告段落；不要用搜索摘要替代原文。
4. 截取能支持命题的正文、表格或官方字段内容截图，记录来源编号和核验记录，并在报告正文对应句子、表格行或评分项后标注 `[Sx]`。
5. 对高风险或时效性命题使用独立来源交叉核验；若来源冲突，保留差异并降级结论。

来源记录至少包含以下字段：

| 字段 | 要求 |
| --- | --- |
| 来源编号 | 使用连续编号，如 `[S1]`；正文与来源表一致 |
| 来源类型 | 内部记录、政府/海关、企业官方、展会主办方、行业机构、聚合/线索 |
| 页面标题与发布方 | 按网页或记录实际内容填写 |
| URL | 外部来源必须是可点击的完整链接；无链接不得标为已核验 |
| 内容截图 | 外部关键事实必须附正文/表格/官方字段截图或页面快照；截图不可用时标为“截图缺失，待核验” |
| 发布/更新时间或生效日期 | 找不到时写“未标明”，不能自行补日期 |
| 检索日期 | 使用实际打开网页的日期 |
| 关键证据 | 摘录短句或记录具体字段，足以复核命题；不得只写页面标题或搜索摘要 |
| 证明范围 | 写明来源支持什么，不支持什么 |
| 商业解读 | 说明事实如何改变市场、产品、买家、报价、渠道或项目判断 |
| 反证/限制 | 记录相反证据、时效风险和页面未证明的范围 |
| 核验状态 | 已打开核验、交叉核验、仅摘要/待核验、冲突待处理 |

关键事实的交叉核验最低要求如下：

| 命题 | 首选来源 | 交叉核验要求 |
| --- | --- | --- |
| 关税、税费、准入、认证、政策利好 | 政府、海关、监管机构 | 有条件时再用目标国官方或专业机构确认适用范围和时效 |
| 市场规模、进口额、增长率 | 官方统计、贸易数据库、行业机构 | 至少核对统计口径、年份和独立数据来源；口径不同不得直接合并 |
| 买家身份、采购/进口行为 | 买家官网、官方目录、内部买家库 | 买家身份与采购行为至少分别核验；没有采购证据只能列为待核验线索 |
| 展会名称、时间、地点、展商/观众角色 | 主办方官网、官方目录 | 时间地点和展会定位至少打开主办方页面核验；历史记录不能代替当前信息 |
| 企业主营、产品和经营状态 | 企业官网、官方公告、注册/监管信息 | 同名或冲突时至少使用两个独立来源确认主体 |

页面不可访问、仅显示搜索摘要、只有转载没有原始链接、链接失效、关键正文缺失或无法取得内容截图时，记录为“仅摘要/待核验”或“截图缺失/待核验”。这类信息可以作为线索和待验证事项，但不能作为确定性事实、排名、税率或推荐买家的唯一依据。来源表不得用一个泛链接替代具体事实的证据链接。

## 证据等级

根据结论类型选择来源，不把所有来源混为同一可信度：

1. 政府、海关、官方贸易或监管机构：关税、政策、认证和准入。
2. 企业官网、官方公告、年报和官方注册信息：企业主营、产品、所在地和近期动态。
3. 展会主办方官网、官方展商目录和官方现场资料：参展和展会事实。
4. 权威行业媒体、协会和研究机构：行业趋势、市场需求和竞争环境。
5. 聚合数据库、搜索结果页、销售线索平台和历史素材：发现线索，不作为唯一证据。

内部系统适合证明企业与本企业的历史关系、内部项目或历史筛选结果；对当前状态、最新政策和外部事实仍需联网复核。

## 证据链

把关键事实登记为来源编号，例如 `[S1]`、`[S2]`，在结论、评分表和买家表中回链。每个外部事实必须在正文对应位置出现来源编号；每个重要命题至少记录：

- 来源编号、名称或工具名称；
- 记录标题、企业或对象标识；
- 网页标题和发布方；
- URL 或内部记录链接；
- 支持命题的网页内容截图或截图缺失状态；
- 发布日期、生效日期或数据更新时间；
- 检索日期；
- 支撑结论的关键字段或原文要点；
- 来源只证明什么，不证明什么。
- 对产品、市场、买家、报价或项目判断的商业解读；
- 可能的反证、限制和结论影响。

主报告中的来源表应能回答：这条数据支持了哪一个结论，数据口径是什么，什么时候可能失效。来源表中的外部 URL 使用 Markdown 链接，例如 `[官方公告](https://example.com/...)`。把 URL 全部堆在文末而不在正文标记来源编号，不算完整引用。

## 结论表达

使用以下结构展示可审计的判断依据：

`关键命题 → 支持事实 [Sx] → 推论 → 限制/反证 → 验证动作`

这不是输出私有思维链，而是简洁的事实、判断和行动记录。不要把检索步骤、关键词、工具返回顺序或内部推理过程原样写进报告。

## 冲突处理

当内部记录和外部来源不一致时：

1. 保留内部记录和外部结果两边的内容。
2. 优先最新且权威的来源，但说明优先理由。
3. 生成校正建议，不自动写回客户关系库、展会历史记录库或其他业务系统。
4. 在报告中标注影响范围，例如“影响企业主营判断”或“只影响参展年份”。

## 数据口径

市场规模、增长率、进口额、价格、展会规模和买家数量必须注明：

- 统计对象和范围；
- 货币和单位；
- 年份或时间区间；
- 是产品细分、相邻行业还是泛行业；
- 是否为估算、预测或实际统计。

如果来源只覆盖相邻行业，正文必须写“方向性证据”，不能改写成目标产品的精确规模。

## 置信度

- 高：权威或官方来源支持，并有独立的产品、渠道或市场证据交叉验证。
- 中：主要命题有可靠来源，但产品细分、时间、价格或渠道证据仍缺一部分。
- 低：主要依赖推断、历史素材、聚合库、不完整内部结果或泛行业数据。

置信度描述证据质量，不等同于市场吸引力分数。低置信度不能支撑“优先进入”或“推荐开发”措辞。
