# 数据源适配

## 适配目标

把飞书智能体已经暴露的技能、CLI、Base 或联网入口映射为稳定的逻辑数据源。不要假设入口对应完整后台权限；以实际返回字段和权限范围为准。

## 首次配置清单

逐项确认以下逻辑入口的实际工具名称、调用参数、筛选能力、返回字段、更新时间字段和权限边界：

| 逻辑入口 | 必须确认的能力 |
| --- | --- |
| CRM | 客户、商机、合同、拜访、展会或项目记录的查询；敏感字段是否已过滤 |
| Selection 企业库 | 企业名称、行业、产品、国家、出口、规模、展商标签和参展记录 |
| Selection Buyers / CDP | 买家国家、行业、产品、采购方向、规模和匹配筛选 |
| 飞书 Base | 展会、企业、国家、展位、展品、现场照片和历史记录查询 |
| 米奥兰特项目/展会 | 在已有项目入口、飞书 Base 或项目记录中确认项目 ID、米奥兰特归属、国家、产品范围、日期、状态和历史参展字段；不能新增表 |
| 历史展商素材库 | 同行、展会、展品、素材类型、发布时间和附件链接 |
| 内容中心 | 国家、产品、素材标题、推送时间、正文或链接查询 |
| 联网搜索 | 搜索、打开网页、读取正文、返回 URL、标题和发布时间 |
| 飞书云文档 | 创建文档、写入正文、返回文档链接；不需要业务库写权限 |

## 配置保存

配置只写入 Skill 或飞书智能体的已有配置区域，不创建新的 Base 或业务记录。配置应记录逻辑入口与实际工具的对应关系，例如：

```text
crm = <当前智能体中的 CRM 查询工具>
enterprise_selection = <当前智能体中的 Selection 企业库工具>
buyer_selection = <当前智能体中的 Selection Buyers/CDP 工具>
exhibition_base = <当前智能体中的飞书 Base 工具>
miolante_projects = <当前智能体中的米奥兰特项目/展会查询入口；可与已有 Base 入口相同>
peer_materials = <当前智能体中的历史展商素材工具>
content_center = <当前智能体中的内容中心工具>
web_research = <当前智能体中的联网搜索工具>
feishu_doc = <当前智能体中的云文档创建工具>
```

如果平台不能持久化 Skill 内配置，要求管理员在智能体的 Skill 配置或工具说明中填入上述逻辑映射；不要在对话中索要账号、密码或密钥。

## 适配验证

使用一个已知企业做只读测试，至少验证：

1. CRM 能返回客户关系摘要，且不暴露金额和联系人。
2. Selection 企业库能按企业名称或国家筛选。
3. 买家库能按国家和产品方向筛选。
4. Base 能返回历史展会或现场记录。
5. 米奥兰特项目入口能返回项目 ID、国家、产品范围、日期和当前状态；无法返回时不得推荐展会。
6. 同行素材库和内容中心能返回素材时间与链接。
7. 联网入口能打开正文并返回来源。
8. 云文档入口能创建测试报告。

测试失败时记录“入口不可用”或“字段不可见”，不要改写业务数据来绕过问题。

## 查询状态

每个内部数据源都应返回以下状态之一：

- `matched`：找到并读取到相关记录。
- `no_result_in_accessible_scope`：在当前可访问范围内无结果。
- `permission_or_tool_limited`：入口不可用、字段被过滤或权限不足。
- `insufficient_input`：输入不足以执行可靠查询。
