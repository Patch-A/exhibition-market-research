# 数据源适配

## 适配目标

把飞书智能体已经暴露的查询、联网和文档入口映射为稳定的逻辑数据源。不要假设入口对应完整后台权限；以实际返回字段和权限范围为准。本公开文件只使用逻辑角色名，具体工具名、租户信息和权限配置放在飞书智能体私有配置中。

## 首次配置清单

逐项确认以下逻辑入口的实际工具名称、调用参数、筛选能力、返回字段、更新时间字段和权限边界：

| 逻辑入口 | 必须确认的能力 |
| --- | --- |
| 客户关系库 | 客户、商机、合同、拜访、展会或项目记录的查询；敏感字段是否已过滤 |
| 企业/展商库 | 企业名称、行业、产品、国家、出口、规模、展商标签和参展记录 |
| 海外买家库 | 买家国家、行业、产品、采购方向、规模和匹配筛选 |
| 展会历史记录库 | 展会、企业、国家、展位、展品、现场照片和历史记录查询 |
| 关联会展企业项目池 | 在已有项目入口或历史记录中确认关联会展企业归属、项目 ID、国家、产品范围、日期、状态和历史参展字段；不能新增表 |
| 同行/展商素材库 | 同行、展会、展品、素材类型、发布时间和附件链接 |
| 运营内容中心 | 国家、产品、素材标题、推送时间、正文或链接查询 |
| 联网研究入口 | 搜索、打开网页、读取正文、返回 URL、标题和发布时间，并取得正文/表格/官方字段截图或页面快照 |
| 飞书云文档 | 创建文档、写入正文、返回文档链接；不需要业务库写权限 |

## 配置保存

配置只写入飞书智能体的已有私有配置区域，不创建新的业务表或业务记录。配置应记录逻辑入口与实际工具的对应关系，例如：

```text
customer_relationship_source = <首次适配时配置的客户关系查询入口>
enterprise_exhibitor_source = <首次适配时配置的企业/展商查询入口>
overseas_buyer_source = <首次适配时配置的海外买家查询入口>
exhibition_history_source = <首次适配时配置的展会历史记录查询入口>
associated_project_source = <首次适配时配置的关联会展企业项目池查询入口>
peer_material_source = <首次适配时配置的同行/展商素材查询入口>
operations_content_source = <首次适配时配置的运营内容查询入口>
web_research_source = <首次适配时配置的联网研究入口>
feishu_document_source = <当前智能体中的云文档创建入口>
```

如果平台不能持久化 Skill 内配置，要求管理员在智能体的 Skill 配置或工具说明中填入上述逻辑映射；不要在对话中索要账号、密码或密钥。

关联会展企业名称、项目归属和项目池范围属于首次适配配置，不写死在 Skill 中，也不默认等同于本次查询的研究对象企业。运行时使用研究对象企业的产品、国家和显式企业关联字段进行匹配；没有明确关联字段时，只能说明“项目匹配”，不能声称该企业已有项目或历史参展。

## 适配验证

使用一个已知企业做只读测试，至少验证：

1. 客户关系库能返回客户关系摘要，且不暴露金额和联系人。
2. 企业/展商库能按企业名称或国家筛选。
3. 海外买家库能按国家和产品方向筛选。
4. 展会历史记录库能返回历史展会或现场记录。
5. 关联会展企业项目池能返回项目 ID、国家、产品范围、日期和当前状态；无法返回时不得推荐展会。
6. 同行/展商素材库和运营内容中心能返回素材时间与链接。
7. 联网研究入口能打开正文、返回来源链接，并能截取支持命题的网页内容；不能截图时必须能明确返回能力缺口。
8. 云文档入口能创建测试报告。

测试失败时记录“入口不可用”或“字段不可见”，不要改写业务数据来绕过问题。

## 查询状态

每个内部数据源都应返回以下状态之一：

- `matched`：找到并读取到相关记录。
- `no_result_in_accessible_scope`：在当前可访问范围内无结果。
- `permission_or_tool_limited`：入口不可用、字段被过滤或权限不足。
- `insufficient_input`：输入不足以执行可靠查询。

外部网页证据还要记录 `screenshot_available` 或 `screenshot_unavailable`。截图不可用不等于网页事实不存在，但该事实不能标记为完整核验，也不能单独支撑市场排名、买家推荐、政策/关税结论或展会 go/no-go。
