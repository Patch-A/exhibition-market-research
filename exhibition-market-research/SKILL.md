# 展会市场进入研究

## 目标

围绕一个明确的市场进入决策，完成“按事实类型选择数据源顺序、外部证据截图核验、市场论证、买家与竞品分层、展会与行动建议、飞书云文档交付”的研究闭环。使用已接入的飞书智能体逻辑入口；不要假设可以访问未暴露的底层数据库。具体顺序必须遵循 [research-routing.md](references/research-routing.md)，不能把所有对象一概处理为“内部优先”或“联网优先”。

把检索结果转换为销售和市场部可执行的判断。每份报告必须回答：**卖什么、卖给谁、为什么是这个市场、通过什么渠道进入、需要先验证什么、下一步谁做什么。**

## 公开版本边界

本仓库及其 Skill 页面按公开发布处理。只能使用逻辑角色名、占位符和虚构示例，不得写入具体关联企业名称、真实客户/展商名称、个人姓名、联系方式、合同或金额、真实租户/内部链接、记录 ID、访问令牌、字段截图或未脱敏工具名称。实际工具映射、权限范围和企业专属配置只保存在飞书智能体的私有配置中，不回写公开仓库。

## 报告分级与发布门槛

先阅读 [report-quality-gates.md](references/report-quality-gates.md)，再决定输出类型。

### 市场进入决策报告

仅在产品、市场和业务目标足够明确时使用。报告必须有产品或 SKU/CAS/OEM/应用场景、目标国家或候选市场、研究决策问题，以及与结论对应的市场、买家、准入或展会证据。标题使用：

`市场进入决策报告｜{企业或产品}｜{市场}｜{日期}`

### 市场验证报告

产品族、应用和目标市场已知，但 SKU、价格、采购能力或合规细节仍不足时使用。报告仍必须解读当前市场商机/政策、关联会展企业项目匹配、买家与同行证据、HS/准入商业影响和 30 天补证动作；只能把结论降级为“验证机会/待确认”，不能退化为网页摘录或简单资料汇总。标题使用：

`市场验证报告｜{企业或产品}｜{市场}｜{日期}`

### 市场机会探索简报

企业、品牌、SKU、产品规格或目标市场不足时使用。可以提出方向性假设、渠道画像和待核验线索，但不得伪装成完整市场报告，不得给出精确 HS 税率、确定采购名单或无证据的市场排名。标题使用：

`市场机会探索简报｜{企业或产品}｜{日期}`

不要在主报告中出现“v2 修订说明”“工具未映射”“数据库噪音高”等过程性叙事。将研究边界、数据缺口和数据源状态放入“研究边界与待验证事项”或附录。

## 运行模式

### 首次适配

首次使用或工具入口发生变化时，先阅读 [data-source-adaptation.md](references/data-source-adaptation.md)，以逻辑数据源确认当前可调用入口、查询对象、返回字段和权限限制。将确认结果保存在飞书智能体私有配置中，不写入公开仓库，也不创建新的业务表或配置表。

若入口名称、参数或权限无法确认，报告缺失项并请求管理员配置；不要猜测工具名称、字段或查询结果。

### 日常执行

收到调研请求后，按 [research-routing.md](references/research-routing.md) 的十步顺序执行。除创建最终飞书云文档外，所有业务数据源均为只读。

## 输入解析

识别以下字段：

- 企业名称或品牌：企业报告必填；产品报告可选。
- 官网或企业链接：优先用于消除同名企业和核验产品。
- 产品名称、产品描述、产品链接、SKU、CAS、OEM 号、图片或目录：市场、买家、HS 和准入分析的关键输入。
- 应用场景、目标客户和价格带：用于形成市场进入假设。
- 目标国家或地区：存在时进入目标市场模式。
- 业务目标：找经销商、验证需求、开发终端客户、评估展会、启动报价或建立出海优先级。
- 目标展会、预算或时间窗口：可选。

只有企业名称时，先完成企业识别、内部关系查询和基础公开研究。若无法可靠识别产品，输出探索简报，明确最小补充信息；不要用泛行业数据制造产品级结论。

## 数据源路由

按逻辑职责调用已配置入口：

| 逻辑任务 | 查询顺序 | 用途 |
| --- | --- | --- |
| 客户、合同、商机、拜访 | 客户关系库 → 企业官网/官方公告（仅核验主体与当前状态） | 判断历史客户和内部业务关系；公网不能证明合同关系 |
| 中国企业、展商 | 企业/展商库 → 企业官网/注册或监管页面 | 企业画像、产品、行业、出口和展商信息 |
| 海外买家 | 联网研究入口/官网/官方目录 → 海外买家库 | 先确认当前主体和采购/进口信号，再检查库内命中、标签和可触达性 |
| 渠道结构与进入路径 | 联网研究入口/行业协会/品牌代理页 → 海外买家库、企业/展商库和项目记录 | 判断谁掌握采购、分销和项目入口，再筛选库内可触达对象 |
| 展会照片、展位、现场记录 | 展会历史记录库 → 展会/主办方官方页面 | 查询历史展会、展位、展品和现场关系，并核验当前展会事实 |
| 关联会展企业当前/历史项目 | 首次适配时配置的项目入口或展会历史记录库 → 项目/主办方官方页面 | 唯一展会推荐池、项目 ID、当前状态和历史参展依据 |
| 同行海报、单页、历史展商素材 | 同行/展商素材库、展会历史记录库、企业/展商库 → 同行官网/产品页/案例页 | 先确认内部命中和历史参展，再分析当前同行、竞品和定位 |
| 市场商机、政策/利好/反证 | 政府/监管/统计/行业来源联网搜索 → 运营内容中心、内部项目和企业资料 | 先建立当前市场论证，再用内部素材补充，不把运营内容中心当作当前事实 |
| HS、关税、准入 | 目标国海关/税则/监管机构联网搜索 → 企业 SKU/产品资料和进口商确认 | 先取得官方税费与准入证据，再映射产品情景并判断商业可行性 |
| 已包装推送的运营素材 | 运营内容中心（在市场公网研究后） | 按国家和产品补充可复用内容，标记为内部补充素材 |
| 报告交付 | 飞书云文档 | 创建最终只读研究报告 |
| 水单、付款凭证 | 不调用 | 不属于本 Skill 的研究范围 |

各内部逻辑数据源没有结果时，区分“已命中”“当前可访问范围内无结果”“权限或工具限制”“信息不足”。不要把受权限过滤的无结果写成系统中不存在。

## 决策式研究流程

严格执行 [research-routing.md](references/research-routing.md) 的十步路由：

1. 锁定研究对象、产品、国家和决策问题。
2. 企业身份与客户关系库/企业展商库历史关系采用内部优先，再联网核验。
3. 产品和应用采用销售输入/内部资料优先，再打开官网和技术页面核验。
4. 市场商机、政策利好和反证采用联网优先，再用运营内容中心和内部资料补充。
5. 海外买家先联网发现并核验，再预检海外买家库的检索能力并交叉检查库内状态；库内能力不可靠时阻塞正式买家推荐，不凑数。
6. 渠道结构先联网研究，再用海外买家库、企业/展商库和项目记录筛选可触达对象。
7. 同行先查同行/展商素材库、展会历史记录库、企业/展商库和项目记录，再联网解读；无内部命中时找当地相关产品头部案例。
8. HS、关税、准入先查官方联网来源，再用内部 SKU/产品资料映射并判断商业影响。
9. 展会先从关联会展企业项目池筛选，再打开项目/主办方页面核验，最后补查历史参展记录。
10. 统一截图、链接、来源编号、证据包、反证、脱敏和跨章节一致性后生成飞书云文档。

买家、市场、政策、关税等联网优先项目必须打开正文并保存内容截图；同行、客户关系库、展会历史记录库和关联项目等内部优先项目也必须在需要时联网核验当前状态。截图不可用时降级为“待核验”，不得伪造。

市场商机证据包至少包含：商机判断、证据摘录/截图、来源链接、能证明什么、不能证明什么、业务解读、反证/风险和关联项目承接。关联项目承接只能说明验证或获客节点，不能写成研究对象企业已有客户、历史参展或确定订单。

## 证据与核验

阅读 [research-evidence.md](references/research-evidence.md) 执行来源分级、冲突处理、置信度和引用规则。联网搜索必须先用于发现线索，再打开网页正文核验；搜索结果摘要、搜索结果页或无法打开的页面不能单独支撑结论。

对每个外部事实执行以下强制步骤：

1. 搜索并记录候选结果。
2. 打开原网页，确认页面标题、发布方、发布日期/更新时间或生效日期，以及与命题直接相关的正文、表格或官方字段。
3. 截取能支持命题的网页正文/表格/官方字段内容截图；记录来源编号、可点击 URL、检索日期、关键证据摘录、来源证明的范围和不能证明的范围。
4. 对关税、政策利好、市场规模、买家采购事实、展会时间地点和存在冲突的企业事实，至少用一个独立来源交叉核验。
5. 在正文对应事实或结论后标注来源编号，如 `[S1]`；来源表必须提供该编号对应的可点击链接。无法打开、缺少 URL 或只有摘要的来源必须标为“待核验”，不得写成已核验事实。

每个外部事实、日期、数字、买家/展会判断和政策结论都必须在正文有来源编号或“待核验”标记，并在来源表或证据卡片中提供截图、可点击 URL、解读和限制。不能只在文末堆放 URL。内部库记录也使用来源编号，但要标明“内部记录”，不能把内部记录链接伪装成公开来源。

报告不能停留在来源摘录。每条重要来源都要回答“它说明了什么、对目标产品意味着什么、不能说明什么、是否有反证、结论因此如何变化”；原始页面标题、产品数量或字段内容只能作为证据，不得直接充当结论。报告用市场分析语言表达商业判断，不把“销售该怎么用”写成替代市场结论的教程。

主报告使用简洁的“判断依据”表：`关键命题｜支持事实｜来源编号｜推论｜不确定性｜验证动作`。这提供可复核的决策逻辑，但不暴露私有思维链。内部记录与外部事实分开标注；发现冲突时保留差异并给出校正建议，不自动覆盖内部数据。

## 输出限制

采用“固定上限、证据不足则减少”的推荐数量：最多 3 个市场、10 家买家、5 个关联会展企业项目和 10 条内容素材。用户指定目标市场时，优先分析该市场；额外市场最多 1-2 个，且必须来自当前有效、产品匹配的关联项目国家/地区。默认输出后续验证与进入建议，不生成来源不足的阶段方案；如用户明确要求阶段计划，主体必须是研究对象企业，关联会展企业项目只能作为渠道或验证节点。

报告默认隐藏客户关系库金额、联系人、联系方式、手机号、邮箱、个人身份信息、不必要的合同细节、原始内部记录 ID、私有链接、银行/发票/付款信息。需要跨章节关联时使用安全显示编号或来源别名，不把底层主键和受权限保护的 URL 写入报告。除创建最终报告外，不调用写入、更新、删除、回写或同步业务数据的动作。

## 降级规则

- 内部同行库、展会历史记录库、运营内容中心不可用：在主报告保留同行/渠道和素材建议章节，改用公开可核验来源，并在附录说明数据范围。
- 海外买家库噪音高或不可用：不输出伪精确买家名单；输出买家画像、待核验线索、筛选规则、获取路径和验证动作。
- 产品或 SKU 不足：降低结论粒度，不删除买家、竞品、展会和进入路径章节；输出探索简报和决策门槛。
- 缺少产品级证据：不得以泛市场规模、平台页面或品牌代理信息直接证明产品需求。
- 无法确认 HS 编码：输出候选编码和确认路径，不给出单一确定税率。
- 没有足够高质量证据：减少推荐数量，明确说明研究边界，不用“高分”掩盖证据不足。
- 联网搜索或外部来源未返回：不把行业常识、模型推断或搜索摘要写成已核验事实；只能输出带“假设/待核验”标签的研究方向和补证动作，不输出确定性市场排名。
- 网页无法打开、正文无法读取、来源链接缺失或只有搜索摘要：该事实降级为“待核验”，不得进入无条件的市场排名、买家推荐、税率结论或展会 go/no-go 结论；报告必须给出补证动作。
- 关键网页事实没有内容截图：不得标为完整核验；降级为“截图/正文证据缺失，待核验”，并在研究边界中说明工具能力缺口。
- 没有可确认的关联项目 ID、项目归属、日期或当前状态：不推荐任何展会，也不使用公开展会替代；只输出项目缺口和验证动作。
- 目标市场之外没有当前有效且产品匹配的关联项目：不擅自推荐其他国家；明确说明没有额外项目市场，并列出补证动作。
- 只有页面标题、产品数量、类目或简短字段而没有商业解读：报告不通过发布门槛，必须补写事实含义、适用边界、商业影响和验证条件。
- 竞品或渠道没有来源路径、内部命中状态、历史参展信息或案例解读：只能列为待核验观察线索，不能作为竞品结论或定位依据。
- HS/关税只有编码和税率，没有对报价、认证、物流、渠道毛利或交付的影响分析：准入章节不通过，必须补写商业可行性判断。
- 准入章节只有“销售需要做什么”的动作清单，没有“可进入/条件进入/暂缓报价”的市场判断、成本与合规影响：报告不通过发布门槛。
- 没有当前市场商机、政策利好或不利因素的解读：不得输出“建议进入”式结论；至少写明“未发现可核验利好”及其对推荐的影响。
- 不得把关联会展企业写成产品供应商、研究对象或阶段计划主体；关联项目只能作为展会/获客节点。
