# 展会市场进入研究

## 目标

围绕一个明确的市场进入决策，完成“内部查询优先、外部核验补充、市场论证、买家与竞品分层、展会与行动建议、飞书云文档交付”的研究闭环。使用已接入的飞书智能体技能、CLI 或 Base 入口；不要假设可以访问未暴露的底层数据库。

把检索结果转换为销售和市场部可执行的判断。每份报告必须回答：**卖什么、卖给谁、为什么是这个市场、通过什么渠道进入、需要先验证什么、下一步谁做什么。**

## 报告分级与发布门槛

先阅读 [report-quality-gates.md](references/report-quality-gates.md)，再决定输出类型。

### 市场进入决策报告

仅在产品、市场和业务目标足够明确时使用。报告必须有产品或 SKU/CAS/OEM/应用场景、目标国家或候选市场、研究决策问题，以及与结论对应的市场、买家、准入或展会证据。标题使用：

`市场进入决策报告｜{企业或产品}｜{市场}｜{日期}`

### 市场机会探索简报

企业、品牌、SKU、产品规格或目标市场不足时使用。可以提出方向性假设、渠道画像和待核验线索，但不得伪装成完整市场报告，不得给出精确 HS 税率、确定采购名单或无证据的市场排名。标题使用：

`市场机会探索简报｜{企业或产品}｜{日期}`

不要在主报告中出现“v2 修订说明”“工具未映射”“数据库噪音高”等过程性叙事。将研究边界、数据缺口和数据源状态放入“研究边界与待验证事项”或附录。

## 运行模式

### 首次适配

首次使用或工具入口发生变化时，先阅读 [data-source-adaptation.md](references/data-source-adaptation.md)，以逻辑数据源确认当前可调用入口、查询对象、返回字段和权限限制。将确认结果保存在 Skill 或飞书智能体自身配置中，不创建新的 Base、配置表或业务记录。

若入口名称、参数或权限无法确认，报告缺失项并请求管理员配置；不要猜测工具名称、字段或查询结果。

### 日常执行

收到调研请求后，按以下顺序执行。除创建最终飞书云文档外，所有业务数据源均为只读。

## 输入解析

识别以下字段：

- 企业名称或品牌：企业报告必填；产品报告可选。
- 官网或企业链接：优先用于消除同名企业和核验产品。
- 产品名称、产品描述、产品链接、SKU、CAS、OEM 号、图片或目录：市场、买家、HS 和准入分析的关键输入。
- 应用场景、目标客户和价格带：用于形成市场进入假设。
- 目标国家或地区：存在时进入目标市场模式。
- 业务目标：找经销商、验证需求、开发终端客户、评估展会、启动报价或建立出海优先级。
- 目标展会、预算或时间窗口：可选。

只有企业名称时，先完成企业识别、内部关系查询和基础公开研究。若无法可靠识别产品，输出探索简报，明确最小补充信息；不要用泛行业数据制造产品级结论。

## 数据源路由

按逻辑职责调用已配置入口：

| 逻辑任务 | 首选数据源 | 用途 |
| --- | --- | --- |
| 客户、合同、商机、拜访 | CRM | 判断历史客户和内部业务关系 |
| 中国企业、展商 | Selection 企业库 | 企业画像、产品、行业、出口和展商信息 |
| 海外买家 | Selection Buyers / CDP | 按国家、行业、产品和采购方向筛选买家 |
| 展会照片、展位、现场记录 | 飞书 Base | 查询历史展会、展位、展品和现场关系 |
| 同行海报、单页、历史展商素材 | 历史展商素材库 | 参考同行表达、产品和历史展会项目 |
| 已包装推送的运营素材 | 内容中心 | 按国家和产品补充可复用内容 |
| 当前企业、政策、关税和展会动态 | 联网搜索 | 核验时效性事实并补充外部信息 |
| 报告交付 | 飞书云文档 | 创建最终只读研究报告 |
| 水单、付款凭证 | 不调用 | 不属于本 Skill 的研究范围 |

CRM、Selection、Base、买家库和素材库没有结果时，区分“已命中”“当前可访问范围内无结果”“权限或工具限制”“信息不足”。不要把受权限过滤的无结果写成系统中不存在。

## 决策式研究流程

1. **定义决策问题**：明确要验证的市场进入命题，例如“某 SKU 是否适合通过越南涂料原料分销商切入”。写出成功标准、时间窗口和不做什么。
2. **确认企业与产品**：识别企业主体、官网、产品、应用、技术或材料特征、认证、供应能力和可交付材料。区分销售输入、内部记录和公开来源。
3. **查询内部关系与资产**：查询 CRM、Selection 企业库、飞书 Base、历史展商素材库和内容中心。内部资料用于历史关系、已有展会资产和已验证经验，不代替外部当前事实。
4. **构建市场论证**：阅读 [market-entry-analysis.md](references/market-entry-analysis.md)。从需求场景、目标细分、进口/生产/项目驱动、渠道结构、竞争、准入、价格或采购门槛、展会可触达性形成市场进入命题，而不是只罗列宏观市场数据。
5. **比较市场并形成结论**：阅读 [market-scoring.md](references/market-scoring.md)。对每个候选市场使用同一维度、同一证据要求评分，并把分数、证据、假设和可能改变结论的条件放在同一张比较表中。
6. **分析买家、渠道与竞品**：阅读 [buyer-and-benchmark.md](references/buyer-and-benchmark.md)。严格区分潜在买家、渠道/分销商、竞品、下游用户和平台；不要把同一批公司在不同章节重复称为“买家”。
7. **分析关税与准入**：阅读 [tariff-and-hs.md](references/tariff-and-hs.md)，生成候选 HS 编码，查询目标市场关税、认证、准入、贸易限制和最新利好，并明确编码确认状态。
8. **评估展会与进入路径**：把展会视为获客渠道而不是名单。说明展会能够接触的目标细分、参展/观展目的、替代渠道、投入门槛、预期产出和 go/no-go 条件。
9. **形成行动方案**：给出 30/60/90 天的验证路径、责任角色、需要销售/客户补齐的资料、最小可行产品包和优先开发顺序。
10. **生成报告**：阅读 [report-template.md](references/report-template.md)。用“事实—判断—建议—待验证”展示可审计的判断依据；不要输出私有思维链、检索日志或工具过程。

## 证据与核验

阅读 [research-evidence.md](references/research-evidence.md) 执行来源分级、冲突处理、置信度和引用规则。联网搜索必须先用于发现线索，再打开网页正文核验；搜索结果摘要、搜索结果页或无法打开的页面不能单独支撑结论。

对每个外部事实执行以下强制步骤：

1. 搜索并记录候选结果。
2. 打开原网页，确认页面标题、发布方、发布日期/更新时间或生效日期，以及与命题直接相关的正文、表格或官方字段。
3. 记录来源编号、可点击 URL、检索日期、关键证据摘录、来源证明的范围和不能证明的范围。
4. 对关税、政策利好、市场规模、买家采购事实、展会时间地点和存在冲突的企业事实，至少用一个独立来源交叉核验。
5. 在正文对应事实或结论后标注来源编号，如 `[S1]`；来源表必须提供该编号对应的可点击链接。无法打开、缺少 URL 或只有摘要的来源必须标为“待核验”，不得写成已核验事实。

每个外部事实、日期、数字、买家/展会判断和政策结论都必须在正文有来源编号或“待核验”标记。不能只在文末堆放 URL。内部库记录也使用来源编号，但要标明“内部记录”，不能把内部记录链接伪装成公开来源。

主报告使用简洁的“判断依据”表：`关键命题｜支持事实｜来源编号｜推论｜不确定性｜验证动作`。这提供可复核的决策逻辑，但不暴露私有思维链。内部记录与外部事实分开标注；发现冲突时保留差异并给出校正建议，不自动覆盖内部数据。

## 输出限制

采用“固定上限、证据不足则减少”的推荐数量：最多 3 个市场、10 家买家、5 个展会和 10 条内容素材。用户指定目标市场时，优先分析该市场，最多补充 2 个替代市场。

报告默认隐藏 CRM 金额、联系人、联系方式、个人身份信息和不必要的合同细节。不要输出水单或付款凭证信息。除创建最终报告外，不调用写入、更新、删除、回写或同步业务数据的动作。

## 降级规则

- 内部同行库、历史展商素材库、Base 或内容中心不可用：在主报告保留同行/渠道和素材建议章节，改用公开可核验来源，并在附录说明数据范围。
- Selection Buyers/CDP 噪音高或不可用：不输出伪精确买家名单；输出买家画像、待核验线索、筛选规则、获取路径和验证动作。
- 产品或 SKU 不足：降低结论粒度，不删除买家、竞品、展会和进入路径章节；输出探索简报和决策门槛。
- 缺少产品级证据：不得以泛市场规模、平台页面或品牌代理信息直接证明产品需求。
- 无法确认 HS 编码：输出候选编码和确认路径，不给出单一确定税率。
- 没有足够高质量证据：减少推荐数量，明确说明研究边界，不用“高分”掩盖证据不足。
- 联网搜索或外部来源未返回：不把行业常识、模型推断或搜索摘要写成已核验事实；只能输出带“假设/待核验”标签的研究方向和补证动作，不输出确定性市场排名。
- 网页无法打开、正文无法读取、来源链接缺失或只有搜索摘要：该事实降级为“待核验”，不得进入无条件的市场排名、买家推荐、税率结论或展会 go/no-go 结论；报告必须给出补证动作。
