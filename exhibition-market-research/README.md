# 展会市场调研 Skill

面向国际会展企业的企业、市场、买家与展会分析 Skill，主要运行在飞书智能体中。

它按照“内部数据查询优先、联网核验补充、市场与买家分析、同行和展会判断、飞书云文档交付”的流程工作，帮助市场部和销售快速完成客户研究、出海市场判断和展会项目准备。

## 适用场景

- 输入中国企业或参展企业名称，判断是否为历史客户或已有业务记录。
- 查询企业产品、行业、展商信息、历史参展和同行资料。
- 分析产品适合进入的国家或地区，也支持指定目标市场分析。
- 推荐 Selection Buyers / CDP 中的海外买家，并判断可能采购的具体产品。
- 查询候选 HS 编码、关税、认证、准入要求和最新政策。
- 推荐适合关注的展会，并补充内容中心中已有的国家/产品运营素材。
- 自动创建飞书云文档格式的调研报告。

## 工作流

```text
输入企业名称、产品或目标市场
        ↓
CRM 查询客户、合同和业务关系
        ↓
Selection 企业库查询中国企业和展商信息
        ↓
飞书 Base 查询展会现场与历史同行
        ↓
历史展商素材库、内容中心补充素材
        ↓
联网打开网页并核验企业、展会、政策和关税
        ↓
市场评分、买家匹配、同行与展会分析
        ↓
创建飞书云文档报告
```

## 已支持的数据源职责

| 数据源 | 用途 |
| --- | --- |
| CRM | 客户、商机、合同、拜访和历史业务关系 |
| Selection 企业库 | 中国企业、展商、产品、行业和出口信息 |
| Selection Buyers / CDP | 海外买家筛选和采购方向匹配 |
| 飞书 Base | 展会照片、展位、现场记录和历史同行 |
| 历史展商素材库 | 同行海报、单页和历史展商素材 |
| 内容中心 | 按国家和产品查询已包装、已推送的运营素材 |
| 联网搜索 | 打开网页正文，核验事实、关税、政策和展会动态 |
| 飞书云文档 | 输出最终调研报告 |

水单、付款凭证等财务资料不属于本 Skill 的研究范围。

## 飞书智能体接入

首次接入时，将 Skill 中的逻辑数据源映射到飞书智能体已经配置的工具入口：

```text
CRM 客户/合同入口
Selection 企业库入口
Selection Buyers / CDP 入口
飞书 Base 展会历史入口
历史展商素材库入口
内容中心入口
联网搜索入口
飞书云文档创建入口
```

不要求新增 Base 或配置表，也不要求拥有底层数据库的完整后台权限。Skill 按当前智能体实际可访问的入口和权限执行。

## 输入示例

```text
请调研江苏某某机械有限公司，主营工业激光切割设备，重点分析德国、波兰和土耳其市场，推荐海外买家和适合参加的展会，并生成飞书云文档报告。
```

只有企业名称时，Skill 会先完成企业识别和基础研究。无法可靠识别产品时，会标记市场、买家和 HS 编码结论为待补充，不编造具体产品信息。

## 报告内容

报告默认包括：

1. 调研结论摘要
2. 企业基本情况和 CRM 关系
3. 内部信息与外部核验差异
4. 产品与目标市场分析
5. 关税、候选 HS 编码和准入政策
6. 海外买家推荐及可能采购产品
7. 同行与历史参展分析
8. 推荐展会
9. 内容中心可复用素材
10. 销售跟进建议
11. 来源、检索时间、置信度和待确认事项

推荐结果采用固定上限、证据不足则减少：最多 3 个市场、10 家买家、5 个展会和 10 条内容素材。

## 权限与只读规则

- CRM、Selection、Base、买家库和素材库只读。
- 只允许创建最终飞书云文档，不修改业务数据。
- 默认隐藏 CRM 金额、联系人、联系方式、个人身份信息和不必要的合同细节。
- 内部记录与外部核验结果分开呈现，不自动覆盖或写回原始数据。
- 推断的 HS 编码必须标注“待确认”，不能当作确定编码或正式报关意见。
- 入口无权限或查询范围不完整时，报告会明确说明影响范围。
